# NexCalc Premium Calculator

A high-fidelity glassmorphic calculator with a sleek dark theme and precise arithmetic logic.

## 🚀 Features

- **Standard Operations**: Addition, subtraction, multiplication, and division.
- **Advanced UI**: Glassmorphic buttons and display.
- **History Tracking**: Keeps track of your current calculation.
- **Responsive Layout**: Works perfectly on mobile and desktop.

## 🛠️ Technologies Used

- **HTML5**, **CSS3**, **JavaScript**
